# Updating the site — a guide for Christine

Short version: **the class schedule lives in a Google Sheet that you own and edit.**
Change the sheet, reload the website, and the new dates are there. No code, no
login to anything new, works from your phone.

Everything else on the site (prices, workshops, photos, wording) is a quick
change Alex makes — send it over and it's usually done the same day.

---

## 1. The class schedule — yours to edit

Your sheet: **[paste the sheet link here once it's set up]**

It looks like this:

| Date | Time | Class | Price | Format | Note |
|---|---|---|---|---|---|
| 2026-10-13 | 9:30 – 10:45 AM | Morning Magic | | | |
| 2026-10-15 | 9:30 – 10:45 AM | Morning Magic | | | Extra long savasana |
| 2026-10-17 | 10:15 – 11:30 AM | Vitality Flow | $22 | In person | |

**To add two weeks of classes:** click the first empty row, type the date and
time, and type the class name. That's it — the website picks it up the next
time anyone loads the page.

A few things worth knowing:

- **Dates** can be typed however Google offers them — `10/13/2026`, `Oct 13, 2026`
  or `2026-10-13` all work. The easiest way is to select a row you already
  typed, copy it, paste it below, and change the dates.
- **Past classes disappear by themselves.** You never have to delete anything.
  Your sheet becomes a nice record of what you've taught.
- **Price** — leave it blank and the class shows the normal rate. Fill it in
  only when a particular class costs something different.
- **Format** — leave it blank for Zoom. Type `In person` or `Hybrid` when it isn't.
- **Note** — anything special about that one day ("bring a blanket", "90 minutes
  this week"). It shows under the class in a warm colour. Leave it blank most of
  the time.
- **Class** — use the same name each time: `Morning Magic` or `Vitality Flow`.
  The description, level and the Register button come from the name, so spelling
  it the same way is the one thing to be careful about. A new class name shows up
  fine, it just won't have a description until Alex adds one.
- **Don't rename the top row** (Date, Time, Class, Price, Format, Note) and don't
  delete the columns. Order doesn't matter, names do.

If the sheet is ever unreachable, the website falls back to the last list Alex
had in the code — so a bad moment at Google never leaves the schedule blank.

## 2. What to send Alex

These aren't in the sheet, because they change rarely and look better when
they're laid out by hand:

- Rates
- Workshops, retreats and SMHD sessions ("Coming up")
- Class descriptions, your bio, any wording
- Photos — retreat photos, new headshots
- Testimonials

Email them the way you'd write them to a student, and they go up as you wrote them.

## 3. If you ever want to do more yourself

Everything on the site is one small file that a person can read — Alex can walk
you through editing it directly, the same way you edit the sheet, if you get
curious. There's no hurry; the sheet covers the thing that actually changes.
